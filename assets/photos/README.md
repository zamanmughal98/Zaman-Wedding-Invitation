# Personal photographs

Add the two childhood photographs here when they are ready, then update the portrait fields in `config/wedding.js`:

- `couple.groom.photo: '/assets/photos/zaman-childhood.webp'`
- `couple.bride.photo: '/assets/photos/nimra-childhood.webp'`

Both fields are currently empty, so the invitation shows matching initials. The frames keep the same proportions with or without photographs. If a photo cannot load, its initial remains visible.

Use `photoPosition` to adjust each crop and `photoAlt` to describe the photograph. The configured childhood-photo descriptions can be changed if you choose different portraits.

Other image fields remain available:

- `invitation.heroPhoto: '/assets/photos/couple.webp'`
- `gallery.photos[0].src: '/assets/photos/garden.webp'`

Use WebP or JPEG, ideally under 400 KB per image. Add only photographs you want invitation visitors to see.
