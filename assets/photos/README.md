Add personal photographs to this folder, then set the matching path in `config/wedding.js`.

Examples:

- `invitation.heroPhoto: '/assets/photos/couple.webp'`
- `couple.bride.photo: '/assets/photos/bride.webp'`
- `gallery.photos[0].src: '/assets/photos/garden.webp'`

Use WebP or JPEG, ideally under 400 KB per image. Write a descriptive `alt` for gallery images. Adjust the matching `position` field to control cropping. Until an image is supplied, the site uses its themed illustration.
