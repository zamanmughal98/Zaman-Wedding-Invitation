# Guest language resource

`GuestLocale.html` is generated by `npm run sync:locales` for the separate existing photo uploader. It contains public guest copy only. The private uploader implementation remains in `.local/google-photos/` on the owner's machine.

The existing **Zaman & Nimra Wedding Photos** deployment uses a combined Code.gs. Run `npm run sync:locales`, then paste the generated **`.preview/google-photos/Code.gs`** into its existing Code.gs; no separate HTML file is needed there. This GuestLocale resource is bundled automatically.

Follow [the deployment guide](../../docs/urdu-setup.md#activate-the-separate-photo-uploader). Do not place this resource in the wishes project in place of that project's own GuestLocale resource.
